# ARIA — Property Intelligence
### Automated Real Estate Intelligence Architecture
#### Powered by SOMA — Systems Over Manual Action

## What is this?

A personal property deal analysis tool. Fill in a property's details, costs, works specification, and offer strategy — and get an AI-powered deal analysis in seconds. Works on iPhone, Android, iPad, and desktop. Installs like a proper app. Your data stays on your device.

---

## Files in this folder

- `index.html` — the entire app
- `manifest.json` — makes it installable as an app
- `sw.js` — service worker (makes it work offline)
- `icon-192.svg` — app icon
- `icon-512.svg` — large app icon

---

## How to get it live (10 minutes)

### Step 1 — Create a free Vercel account
Go to vercel.com and sign up. Free. No credit card needed.

### Step 2 — Upload your files
- Click "Add New Project"
- Choose "Deploy from file upload" or connect to GitHub
- Upload this entire folder
- Click Deploy

### Step 3 — Get your URL
Vercel gives you a URL like `aria-deals.vercel.app`. That's your app. Share it with anyone.

### Step 4 — Custom domain (optional)
Buy a domain (aria-property.co.uk for example) from Namecheap — about £10/year. Point it to Vercel in 5 minutes. Now it looks completely professional.

---

## How to install on iPhone

1. Open the URL in Safari
2. Tap the Share button (the square with the arrow)
3. Tap "Add to Home Screen"
4. Tap "Add"
5. ARIA appears on your home screen like a proper app

## How to install on Android

1. Open the URL in Chrome
2. Tap the three dots menu
3. Tap "Add to Home Screen" or "Install App"
4. Done

---

## Getting your API key

1. Go to console.anthropic.com
2. Create a free account
3. Go to API Keys
4. Create a new key
5. Copy it
6. In ARIA, tap the ⚙ button and paste it in

Each deal analysis costs approximately 1-3p. Very cheap.
